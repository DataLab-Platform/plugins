DataLab plugins

Extend DataLab with plugins from the DataLab team and the community. Each release is checked automatically (pure Python, open-source license, dependencies provided by DataLab) and mirrored here with its SHA-256 digest.

How to install a plugin

  1. In DataLab 1.4 or later Open Plugins > Configure plugins..., select the Catalog tab and click Install. DataLab downloads the plugin and checks it against this catalog.
  2. From a downloaded file Download a plugin below, then click Install from file... in the From file tab of the same dialog. This also works with the standalone version of DataLab.

Plugins run with the same rights as DataLab: install only plugins from authors you trust. Official plugins are maintained by the DataLab team, community plugins by their authors. Being listed here does not mean that a plugin was audited.

Create your own plugin

A plugin can be a single Python file. Publishing it takes a GitHub repository and one pull request: no PyPI account is needed.

  1. Write it Run datalab-plugin create, installed with the DataLab Python package: it writes a ready-to-use plugin file. Edit it, then select Plugins > Reload plugins in DataLab to try your changes.
  2. Release it Push the source to a public GitHub repository under an open-source license, and attach the plugin file (a datalab_<name>.py module or a wheel) to a GitHub release.
  3. List it Open a pull request adding one YAML file to the catalog repository. Once its automatic checks pass and it is merged, your plugin appears here and in the Catalog tab of DataLab.
